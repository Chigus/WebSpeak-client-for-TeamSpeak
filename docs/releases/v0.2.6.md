# WebSpeak 0.2.6

本版本相对于 [0.2.5 正式版](https://github.com/EchoSixHIYA/WebSpeak-client-for-TeamSpeak/releases/tag/v0.2.5) 更新。

## 问题修复与功能

- **已修复 [#10](https://github.com/EchoSixHIYA/WebSpeak-client-for-TeamSpeak/issues/10)**：Docker/Compose 环境下短主机名的本地 DNS 解析回退；云端昵称发现加入超时和直接连接回退，避免外部发现服务不可用时阻塞连接。HTTPS 部署的健康检查也会根据证书配置选择 HTTPS。
- **已实现 [#9](https://github.com/EchoSixHIYA/WebSpeak-client-for-TeamSpeak/issues/9)**：导入 TeamSpeak 3 身份 INI 或身份字符串、导出 WebSpeak/TeamSpeak 兼容身份，并在本地校验格式和密钥一致性。
- **已修复 [#6](https://github.com/EchoSixHIYA/WebSpeak-client-for-TeamSpeak/issues/6)**：静音同步遇到服务端频率限制时有限重试；会话切换或重连后，旧请求不会覆盖当前麦克风状态。
- **已修复 [#7](https://github.com/EchoSixHIYA/WebSpeak-client-for-TeamSpeak/issues/7)**：TS6 屏幕共享清理等待服务器确认，携带清理原因并对频率限制有限重试，避免本地提前显示清理成功。
- **已实现 [#12](https://github.com/EchoSixHIYA/WebSpeak-client-for-TeamSpeak/issues/12) 请求的配置入口**：管理员可设置公网媒体地址、IPv6 候选和语音 STUN，以适配反向代理或 TCP 隧道后的 UDP 媒体路径。直接媒体仍要求 UDP 可达，STUN 不提供中继。
- 修复 [PR #13](https://github.com/EchoSixHIYA/WebSpeak-client-for-TeamSpeak/pull/13) 所报告的问题：新 WebSpeak 会话会发现已经开始的 TS6 原生屏幕共享，并将发现过程按服务器协调。PR 本身没有合并。
- 改善语音稳定性：隔离重连前后的音频帧、播放回调、目录事件和性能统计；保留连续 Opus 编码状态，只协商受支持的音频参数；切换麦克风或伴奏设置时尽量保留正在工作的采集链路。
- 改善移动端布局和语音控制，增加语音会话期间的屏幕常亮行为；梳理管理后台状态请求和语音工作区组件边界。

## 发布包与架构

- Windows：`windows-x64.zip`、`windows-arm64.zip`。
- Linux：`linux-x64.tar.gz`、`linux-arm64.tar.gz`。
- Docker：同一镜像标签提供 `linux/amd64` 和 `linux/arm64`。
- Android：分别提供 `arm64-v8a`、`armeabi-v7a`、`x86_64` APK。APK 使用 Android debug 签名，适合手动安装和测试，不是 Google Play 发布包。Android 端的真实 TeamSpeak 连接、双向语音和后台行为仍需真机验收。
- `SHA256SUMS.txt` 列出本次附件的 SHA-256，可用于下载后校验。

## 验证

发布流程运行完整自动化测试和前后端构建；各 Windows/Linux 架构的发布包均启动内置健康检查，Android 流程构建三种 ABI 的 APK。自动化构建成功不等于真实 TeamSpeak 服务器或 Android 真机媒体链路已经验收。
